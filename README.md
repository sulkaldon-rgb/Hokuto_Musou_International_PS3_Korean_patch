# Hokuto_Musou_International_PS3_Korean_patch
늙고 병든 사람이 만든 PS3 북괴무쌍 인터내셔널 한글패치에요


1. 초중요!!! 한글패치 전 한번이라도 RPCS3에서 일어판 북두무쌍 International 을 실행했다면 
   \dev_hdd0\game\BLJM60303-INSTALL\USRDIR\LINKDATA_PS3에 있는 'LINKDATA.A' 파일을 반드시
   삭제할 것. 이게 있으면 절대 한글 안 나옴. 다만 게임 실행한 적 없으면 상관 없음.
2. Hokuto Musou International (Japan, Asia).ISO 15.0GB (16,175,333,376 byte) 준비하셈.
3.
[사용 방법 - 둘 중 하나]
방법 1: ISO 파일을 1_DROP_ISO_OR_DOUBLE_CLICK.bat 위로 드래그.
방법 2: 1_DROP_ISO_OR_DOUBLE_CLICK.bat를 더블클릭한 뒤 ISO 전체 경로를 입력/붙여넣는다.

[패치 ISO 생성 위치]
원본 ISO가 있는 폴더에 자동 생성된다.
예:
원본: D:\GAME\Hokuto Musou International (Japan, Asia).iso
결과: D:\GAME\Hokuto Musou International (Japan, Asia)_Korean_Final.iso

원본 ISO는 수정하거나 삭제하지 않습니다.
이미 같은 이름의 결과 ISO가 있으면 덮어쓰지 않고 중단한다.
